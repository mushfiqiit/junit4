## B) Cause of the warning

The warning is triggered by the `return null;` statement at line 10. Because the method’s return type `T` is unannotated, NullAway treats it as `@NonNull` by default, so returning `null` is considered unsafe. Annotating the return type as `@Nullable` tells NullAway that this method is allowed to return `null`.

// === org/junit/experimental/theories/ParameterSignature.java ===
package org.junit.experimental.theories;

import java.lang.annotation.Annotation;
import javax.annotation.Nullable;

public class ParameterSignature {

  private <T extends Annotation> @Nullable T findDeepAnnotation(
      Annotation[] annotations, Class<T> annotationType, int depth) {
    if (depth == 0) {
      return null;
    }
    for (Annotation each : annotations) {
      if (annotationType.isInstance(each)) {
        return annotationType.cast(each);
      }
      Annotation candidate =
          findDeepAnnotation(each.annotationType().getAnnotations(), annotationType, depth - 1);
      if (candidate != null) {
        return annotationType.cast(candidate);
      }
    }
    return null;
  }
}
