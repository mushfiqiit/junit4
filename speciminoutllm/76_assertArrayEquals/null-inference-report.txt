

A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert#assertArrayEquals` parameter `message` | `@Nullable` | It is already correctly annotated because the JUnit failure message may be omitted/null, and this is the nullable expression being passed along. |
| `org.junit.internal.ComparisonCriteria#arrayEquals` parameter `message` | `@Nullable` | The called method receives the nullable message directly from `Assert.assertArrayEquals`, so its `message` parameter must also accept `null`. |

B) Cause of the warning

The warning is triggered by the call in `Assert.assertArrayEquals`:

```java
new InexactComparisonCriteria(delta).arrayEquals(message, expecteds, actuals);
```

Here, `message` is declared `@Nullable` in `Assert`, but the parameter `message` of `ComparisonCriteria.arrayEquals` is unannotated and therefore treated by NullAway as `@NonNull`. Passing a `@Nullable` value to a `@NonNull` parameter is unsafe, so NullAway reports the warning. Annotating the `message` parameter of `ComparisonCriteria.arrayEquals` as `@Nullable` makes the callee accept null messages, resolving the warning.
