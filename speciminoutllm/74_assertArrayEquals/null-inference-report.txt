

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert.assertArrayEquals(String message, ...)` parameter `message` | `@Nullable` | The existing public JUnit assertion overload already treats the failure message as optional, so it may be null. |
| `org.junit.Assert.internalArrayEquals(String message, Object expecteds, Object actuals)` parameter `message` | `@Nullable` | This private helper only forwards the caller’s possibly-null `message`, so its `message` parameter must also be nullable. |

## B) Cause of the warning

The warning occurs at the call to `internalArrayEquals(message, expecteds, actuals)` inside `assertArrayEquals`. The `message` argument is annotated `@Nullable`, but the corresponding parameter of `internalArrayEquals` has no nullness annotation, so NullAway treats it as `@NonNull` by default. Because a `@Nullable` value is being passed where a `@NonNull` value is expected, NullAway reports an unsafe nullness mismatch. Annotating `internalArrayEquals`’s `message` parameter as `@Nullable` declares that this helper accepts a null message, resolving the warning.
