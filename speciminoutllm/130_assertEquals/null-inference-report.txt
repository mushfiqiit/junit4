// A) Annotation decisions
//
// | location | inferred annotation | one-sentence reason |
// | --- | --- | --- |
// | `org.junit.Assert.assertEquals(String message, double expected, double actual, double delta)` parameter `message` | `@Nullable` | The no-message overload passes `null` as the assertion message, so the message parameter must be allowed to be null. |
//
// B) Cause of the warning
//
// The warning is caused by the call `assertEquals(null, expected, actual, delta)` in the
// no-message overload. The first argument is the literal `null`, but the first parameter of
// the four-argument `assertEquals` method is unannotated, so NullAway treats it as `@NonNull`
// by default. Passing `null` to that `@NonNull` parameter is unsafe. Annotating the `message`
// parameter as `@Nullable` tells NullAway that `null` is an accepted value for the assertion
// message, which resolves the warning without changing the program logic.

// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;

public class Assert {

  public static void assertEquals(@Nullable String message, double expected, double actual, double delta) {
    throw new java.lang.Error();
  }

  public static void assertEquals(double expected, double actual, double delta) {
    assertEquals(null, expected, actual, delta);
  }
}
