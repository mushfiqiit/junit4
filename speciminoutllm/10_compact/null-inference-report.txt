

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `junit.framework.Assert.format` parameter `message` | `@Nullable` | The original `format` implementations explicitly check `message != null` before using it, so this parameter is allowed to be null. |
| `junit.framework.ComparisonCompactor.compact` parameter `message` | `@Nullable` (already present) | This is the already-annotated nullable source of the value being passed to `Assert.format`. |

## B) Cause of the warning

The warning is reported on:

```java
return Assert.format(message, fExpected, fActual);
```

inside `ComparisonCompactor.compact`. The `message` parameter of `compact` is annotated `@Nullable`, so NullAway knows it may be null. However, the `message` parameter of `junit.framework.Assert.format` is unannotated, so NullAway treats it as `@NonNull`. Passing a possibly-null `message` to that unannotated `@NonNull` parameter causes the warning. Annotating `Assert.format`'s `message` parameter as `@Nullable` matches the actual behavior of the original method and resolves the warning.
