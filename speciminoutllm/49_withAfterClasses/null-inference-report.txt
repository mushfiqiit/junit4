| `org.junit.internal.runners.statements.RunAfters.RunAfters(Statement next, List<FrameworkMethod> afters, Object target)` — `target` parameter | `@Nullable` | The warning is caused by passing the literal `null` for `target`, and class-level `@AfterClass` handling may legitimately be invoked with a `null` target for static methods. |

## B) Cause of the warning

On line 19 of `ParentRunner.java`, the code calls:

```java
new RunAfters(statement, afters, null)
```

The third constructor argument is `null`. In the reduced `RunAfters` constructor, the corresponding parameter is declared as:

```java
Object target
```

Under NullAway, an unannotated reference-type parameter is treated as `@NonNull` by default. Therefore, passing the `@Nullable` literal `null` where an unannotated/`@NonNull` `Object` parameter is expected triggers:

```text
[NullAway] passing @Nullable parameter 'null' where @NonNull is required
```

Marking the `target` parameter of `RunAfters` as `@Nullable` tells NullAway that this argument is allowed to be `null`, which resolves the warning.
