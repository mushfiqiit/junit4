

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `junit/framework/TestCase.java`, field `private String fName` | `@Nullable` | The constructor explicitly assigns `null` to `fName`, so the field is not guaranteed to be non-null. |
| all other locations | unchanged | They are not involved in the reported warning. |

## B) Cause of the warning

NullAway treats an unannotated field as `@NonNull` by default. The `TestCase()` constructor is an initializer method, and it assigns `null` to `fName`. Therefore, NullAway cannot guarantee that the `@NonNull` field `fName` has been initialized to a non-null value along all control-flow paths. Annotating `fName` as `@Nullable` tells NullAway that null is a valid value for this field, so the initializer requirement no longer applies.
