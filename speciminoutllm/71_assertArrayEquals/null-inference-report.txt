

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert.internalArrayEquals(String message, Object expecteds, Object actuals)` — first parameter `message` | `@Nullable` | This private helper is called from `assertArrayEquals` with the already-annotated `@Nullable String message`, so the helper must accept a nullable message. |

No other annotations are needed to fix this warning.

## B) Cause of the warning

The warning is triggered by the call `internalArrayEquals(message, expecteds, actuals);` in `assertArrayEquals`. There, `message` is declared `@Nullable`, but the first parameter of `internalArrayEquals` is unannotated and therefore assumed to be `@NonNull` by NullAway. Passing a possibly-null value to a non-null parameter is unsafe. Annotating the `message` parameter of `internalArrayEquals` as `@Nullable` tells NullAway that this method accepts a nullable message, resolving the warning.
