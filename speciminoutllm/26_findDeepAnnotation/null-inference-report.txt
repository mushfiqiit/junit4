## B) Cause of the warning

The warning is on line 12, where the public `findDeepAnnotation(Class<T>)` method returns the result of the private `findDeepAnnotation(Annotation[], Class<T>, int)` helper. The private helper is annotated `@Nullable`, but the public method has no nullability annotation, so NullAway treats its return type `T` as `@NonNull` by default. Returning a `@Nullable` expression from a `@NonNull` return type is therefore unsafe. Annotating the public method’s return type as `@Nullable` matches the actual behavior shown by the original usage sites and resolves the warning.
