

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `org.junit.runners.model.FrameworkMethod#invokeExplosively` parameter `target` | `@Nullable` | `Parameterized.RunnersFactory#allParameters` invokes the `@Parameters` framework method with `null` as the target because the parameters method may be static. |

## B) Cause of the warning

The warning points to the `null` literal passed on line 17:

```java
Object parameters = parametersMethod.invokeExplosively(null);
```

Under NullAway, an unannotated `Object target` parameter is treated as `@Nonnull`, so passing the `null` literal to it is unsafe. Annotating `target` as `@Nullable` in `FrameworkMethod.invokeExplosively` tells NullAway that this parameter may legitimately receive `null`, which resolves the warning.
