

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `RuleContainer.RuleEntry` constructor parameter `Integer order` | `@Nullable` | `orderValues.get(rule)` can return `null` when `rule` is not present in `orderValues`, so the constructor parameter must be allowed to accept `null`. |
| `RuleContainer.orderValues` | leave unannotated / default `@NonNull` | The warning is caused by the nullable return type of `Map.get`, not by the declared value type of the map, so changing this field is not needed to fix this warning. |

## B) Cause of the warning

The warning points to the expression `orderValues.get(rule)` passed as the third argument to `new RuleEntry(...)`. NullAway treats `Map.get(...)` as `@Nullable` because the key may not exist in the map. However, the `RuleEntry` constructor parameter `Integer order` is unannotated, which means it is treated as `@NonNull` by NullAway. Passing a potentially `null` value from `orderValues.get(rule)` to an unannotated `@NonNull` parameter is therefore unsafe. Annotating the `order` parameter as `@Nullable` fixes the warning because it explicitly allows the constructor to receive a `null` order value.

package org.junit.runners;

import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.IdentityHashMap;
import java.util.List;
import javax.annotation.Nullable;
import org.junit.rules.MethodRule;
import org.junit.rules.TestRule;

class RuleContainer {

  private final IdentityHashMap<Object, Integer> orderValues;

  private final List<TestRule> testRules;

  private final List<MethodRule> methodRules;

  static final Comparator<RuleEntry> ENTRY_COMPARATOR;

  private List<RuleEntry> getSortedEntries() {
    List<RuleEntry> ruleEntries = new ArrayList<RuleEntry>(methodRules.size() + testRules.size());
    for (MethodRule rule : methodRules) {
      ruleEntries.add(new RuleEntry(rule, RuleEntry.TYPE_METHOD_RULE, orderValues.get(rule)));
    }
    for (TestRule rule : testRules) {
      ruleEntries.add(new RuleEntry(rule, RuleEntry.TYPE_TEST_RULE, orderValues.get(rule)));
    }
    Collections.sort(ruleEntries, ENTRY_COMPARATOR);
    return ruleEntries;
  }

  static class RuleEntry {

    static final int TYPE_TEST_RULE = 0;

    static final int TYPE_METHOD_RULE = 0;

    RuleEntry(Object rule, int type, @Nullable Integer order) {
      throw new java.lang.Error();
    }
  }
}
