

### A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `org.junit.Assert#assertArrayEquals(String, double[], double[], double)#message` | `@Nullable` | The no-message overload intentionally passes `null` for this parameter, so the parameter must accept null. |

### B) Cause of the warning

The warning is on the call `assertArrayEquals(null, expecteds, actuals, delta);`, where the literal `null` is passed for the `String message` parameter. Because `message` is unannotated, NullAway treats it as `@Nonnull` by default, so passing `null` is reported as unsafe. Marking `message` as `@Nullable` tells NullAway that this parameter may legally be null, which fixes the warning.
