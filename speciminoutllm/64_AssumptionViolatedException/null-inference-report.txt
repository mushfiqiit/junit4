

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `AssumptionViolatedException(String, boolean, Object, Matcher<?>)` parameter `Object value` | `@Nullable` | The deprecated two-argument constructor intentionally passes `null` when no assumption value is present. |
| `AssumptionViolatedException(String, boolean, Object, Matcher<?>)` parameter `Matcher<?> matcher` | `@Nullable` | The deprecated two-argument constructor intentionally passes `null` when no matcher is present. |

## B) Cause of the warning

The warning is caused by the call:

```java
this(assumption, false, null, null);
```

in the two-argument constructor. The four-argument constructor’s `value` and `matcher` parameters are unannotated, so NullAway treats them as `@NonNull`. Passing literal `null` to an unannotated parameter is therefore unsafe. Annotating those two parameters as `@Nullable` declares that `null` is an allowed argument, resolving the warning.
