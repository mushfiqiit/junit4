

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `org.junit.Assert.assertNotEquals(String message, float unexpected, float actual, float delta)` — parameter `message` | `@Nullable` | The no-message overload intentionally calls this method with `null` to indicate that no assertion message is supplied. |

No other annotations are needed for this warning; the `float` parameters are primitives and are not involved in the nullness error.

## B) Cause of the warning

The warning is caused by the expression `null` passed as the first argument on this line:

```java
assertNotEquals(null, unexpected, actual, delta);
```

The target method is:

```java
public static void assertNotEquals(String message, float unexpected, float actual, float delta)
```

Since `message` is unannotated, NullAway treats it as `@NonNull` by default. Passing the `null` literal to that parameter is therefore unsafe. Marking `message` as `@Nullable` tells NullAway that `null` is an intentionally accepted value for this parameter, which resolves the warning.

## C) Corrected annotated code

// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;

public class Assert {

  public static void assertNotEquals(float unexpected, float actual, float delta) {
    assertNotEquals(null, unexpected, actual, delta);
  }

  public static void assertNotEquals(@Nullable String message, float unexpected, float actual, float delta) {
    throw new java.lang.Error();
  }
}
