

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `message` parameter of `Assert.assertArrayEquals(String message, short[] expecteds, short[] actuals)` | `@Nullable` | The two-argument overload passes `null` to this parameter when no message is provided, so it must be allowed to be null. |

## B) Cause of the warning

The warning is on the line:

```java
assertArrayEquals(null, expecteds, actuals);
```

NullAway treats the unannotated `String message` parameter as `@NonNull` by default. Therefore, passing the `null` literal to that parameter is reported as passing a nullable value where a non-null value is required. Annotating `message` as `@Nullable` tells NullAway that this parameter is intended to accept `null`, which resolves the warning.

## C) Corrected annotated code

```java
// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;

import org.junit.internal.ArrayComparisonFailure;

public class Assert {

  public static void assertArrayEquals(
      @Nullable String message, short[] expecteds, short[] actuals)
      throws ArrayComparisonFailure {
    throw new java.lang.Error();
  }

  public static void assertArrayEquals(short[] expecteds, short[] actuals) {
    assertArrayEquals(null, expecteds, actuals);
  }
}


// === org/junit/internal/ArrayComparisonFailure.java ===
package org.junit.internal;

public class ArrayComparisonFailure extends AssertionError {}
```
