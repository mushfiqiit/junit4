## B) Cause of the warning

The warning is reported on line 13, inside the two-argument overload:

```java
assertArrayEquals(null, expecteds, actuals);
```

There, the literal `null` is passed as the first argument to the three-argument `assertArrayEquals` method. Since the `message` parameter is unannotated, NullAway treats it as `@NonNull`, so passing `null` is flagged. Annotating `message` as `@Nullable` makes the `null` message argument valid and fixes this specific warning.

```java
// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;
import org.junit.internal.ArrayComparisonFailure;

public class Assert {

  public static void assertArrayEquals(@Nullable String message, byte[] expecteds, byte[] actuals)
      throws ArrayComparisonFailure {
    throw new java.lang.Error();
  }

  public static void assertArrayEquals(byte[] expecteds, byte[] actuals) {
    assertArrayEquals(null, expecteds, actuals);
  }
}


// === org/junit/internal/ArrayComparisonFailure.java ===
package org.junit.internal;

public class ArrayComparisonFailure extends AssertionError {}
```
