|---|---:|---|
| `BlockJUnit4ClassRunner#getExpectedException(Test)` return type `Class<? extends Throwable>` | `@Nullable` | The method explicitly returns `null` when no expected exception is present, so its return type must be nullable to make the `return null;` statement safe. |

## B) Cause of the warning

The warning is triggered by the `return null;` statement inside `getExpectedException`. Under NullAway, an unannotated return type is treated as `@NonNull`, while a `null` literal is `@Nullable`; therefore returning `null` from a method whose return type is non-null is unsafe. Annotating the method’s return type as `@Nullable` declares that the method may legally return `null`, which resolves the reported warning.
