| `message` parameter of `org.junit.Assert.assertNull(String message, Object object)` | `@Nullable` | The no-message overload intentionally passes `null` for the message, so the message parameter must be allowed to be null. |

B) Cause of the warning

The warning is on line 10, where `assertNull(Object object)` calls `assertNull(null, object)`. The `null` literal is passed to the first parameter, `String message`, of the two-argument `assertNull` method. Because that parameter is unannotated, NullAway treats it as `@NonNull`, so passing `null` is reported as unsafe. Annotating the `message` parameter as `@Nullable` tells NullAway that this parameter is allowed to be null, which resolves the warning.

import javax.annotation.Nullable;

public class Assert {

  public static void assertNull(@Nullable String message, Object object) {
    throw new java.lang.Error();
  }

  public static void assertNull(Object object) {
    assertNull(null, object);

}
