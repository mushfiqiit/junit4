## B) Cause of the warning

The warning points to the `null` literal passed as the fourth argument in:

```java
return new CategoryFilter(matchAny, categories, true, null);
```

NullAway treats unannotated parameters as `@Nonnull` by default, so it considers it unsafe to pass a `null` literal to the unannotated `Class<?>[] exclusions` parameter of the private `CategoryFilter` constructor. Marking that parameter `@Nullable` tells NullAway that the constructor intentionally accepts null exclusions, which resolves the warning.
