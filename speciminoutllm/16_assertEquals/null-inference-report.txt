

A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| First parameter `message` of `junit.framework.Assert.assertEquals(String, String, String)` | `@Nullable` | The two-argument overload explicitly passes `null` as the message, so this parameter is not guaranteed to be non-null. |

No other return type, parameter, or field is involved in this warning, so no other annotations are added.

B) Cause of the warning

The warning occurs on the call `assertEquals(null, expected, actual)` inside the two-argument `assertEquals` method. The first argument is the literal `null`, which is `@Nullable`, but the `message` parameter of the three-argument `assertEquals` method is unannotated and therefore treated as `@NonNull` by NullAway. Annotating that `message` parameter as `@Nullable` tells NullAway that `null` is permitted there, which resolves the warning.

C) Corrected annotated code

```java

package junit.framework;

import javax.annotation.Nullable;

@Deprecated
public class Assert {

  public static void assertEquals(@Nullable String message, String expected, String actual) {
    throw new java.lang.Error();
  }

  public static void assertEquals(String expected, String actual) {
    assertEquals(null, expected, actual);
  }
}
```
