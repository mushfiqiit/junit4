

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert.failNotEquals` parameter `String message` | `@Nullable` | JUnit assertion messages are optional and may be null, so `failNotEquals` should accept a `@Nullable` message. |
| `org.junit.Assert.assertEquals` parameter `String message` | `@Nullable` (already present) | The caller intentionally allows a null message, so this parameter should remain `@Nullable`. |
| Return types of `assertEquals` and `failNotEquals` | unchanged | Both methods return `void` and are not involved in the reported warning. |

## B) Cause of the warning

The warning is produced at the call:

```java
failNotEquals(message, Long.valueOf(expected), Long.valueOf(actual));
```

Here, `message` is declared as `@Nullable String message` in `assertEquals`, but the target method `failNotEquals` declares its `message` parameter as an unannotated `String message`. Under NullAway’s JSR305-style default, an unannotated parameter is treated as `@NonNull`, so passing a possibly-null value is unsafe.

Adding `@Nullable` to the `message` parameter of `failNotEquals` makes its nullability contract match the actual usage: the message is optional and may legitimately be null.

package javax.annotation;
@java.lang.annotation.Target({ java.lang.annotation.ElementType.TYPE_USE, java.lang.annotation.ElementType.TYPE, java.lang.annotation.ElementType.FIELD, java.lang.annotation.ElementType.METHOD, java.lang.annotation.ElementType.PARAMETER, java.lang.annotation.ElementType.CONSTRUCTOR, java.lang.annotation.ElementType.LOCAL_VARIABLE, java.lang.annotation.ElementType.ANNOTATION_TYPE, java.lang.annotation.ElementType.PACKAGE, java.lang.annotation.ElementType.TYPE_PARAMETER})
public @interface Nullable {
}


// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;

public class Assert {

  public static void assertEquals(@Nullable String message, long expected, long actual) {
    if (expected != actual) {
      failNotEquals(message, Long.valueOf(expected), Long.valueOf(actual));
    }
  }

  private static void failNotEquals(@Nullable String message, Object expected, Object actual) {
    throw new java.lang.Error();
  }
}
