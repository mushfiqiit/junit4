| `org.junit.Assert.internalArrayEquals(String message, ...)` parameter `message` | `javax.annotation.Nullable` | This private helper is called with the possibly-null `message` from `assertArrayEquals`, so its `message` parameter must be nullable. |

## B) Cause of the warning

The warning occurs at the call to `internalArrayEquals(message, expecteds, actuals)` in `assertArrayEquals`. The argument `message` is declared `@Nullable` in `assertArrayEquals`, but the parameter `message` in `internalArrayEquals` is unannotated. Under NullAway’s default settings, an unannotated parameter is treated as `@NonNull`, so passing a `@Nullable` value to it is flagged as unsafe. Annotating `internalArrayEquals`’s `message` parameter with `@Nullable` tells NullAway that this helper accepts a null message, resolving the warning.
