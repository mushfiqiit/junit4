

A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `MaxHistory.RememberingListener.starts` field reference | unannotated / `@Nonnull` by default | The map reference itself is not the nullable boxed value being unboxed, so it should remain non-null by default. |
| Value type `Long` in `Map<Description, Long> starts` | `@Nonnull` | The durations stored in this listener’s map are non-null boxed `long` values, and the looked-up duration is expected to be safely unboxed. |
| `Description` parameters in `testFinished` and `putTestDuration` | unannotated / `@Nonnull` by default | `Description` is expected to be non-null as a map key/argument, and its nullability is not the source of this unboxing warning. |

B) Cause of the warning

The warning is on:

```java
long start = starts.get(description);
```

`starts.get(description)` has type `Long`, and NullAway treats the result of `Map.get` as potentially `@Nullable`. Assigning that `Long` directly to the primitive `long start` unboxes it, which would throw `NullPointerException` if the value were null. Annotating the map’s value type as `@Nonnull Long` tells NullAway that the boxed duration value in this context is non-null, so the unboxing is accepted.

package org.junit.experimental.max;

import java.io.Serializable;
import java.util.Map;
import javax.annotation.Nonnull;
import org.junit.runner.Description;
import org.junit.runner.notification.RunListener;

public class MaxHistory implements Serializable {

  void putTestDuration(Description description, long duration) {
    throw new java.lang.Error();
  }

  private final class RememberingListener extends RunListener {

    private Map<Description, @Nonnull Long> starts;

    public void testFinished(Description description) throws Exception {
      long end = System.nanoTime();
      long start = starts.get(description);
      putTestDuration(description, end - start);
    }
  }
}
