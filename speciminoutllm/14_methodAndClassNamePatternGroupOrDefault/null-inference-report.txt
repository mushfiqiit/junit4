| Return type of `Description.methodAndClassNamePatternGroupOrDefault(int, String)` | `@Nullable` | This method can return the nullable `defaultString` when the pattern does not match, and regex groups can also be null, so its result may legitimately be null. |

## B) Cause of the warning

The warning is caused by the `return` statement in `methodAndClassNamePatternGroupOrDefault`:

```java
return matcher.matches() ? matcher.group(group) : defaultString;
```

NullAway treats the method’s return type as `@NonNull` because it is unannotated. However, the returned ternary expression is `@Nullable` because `defaultString` is `@Nullable` and `matcher.group(group)` can also be null. By annotating the method’s return type as `@Nullable`, the method contract correctly says that callers must handle a possible null result.

package org.junit.runner;

import java.io.Serializable;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import javax.annotation.Nullable;

public class Description implements Serializable {

  private static final Pattern METHOD_AND_CLASS_NAME_PATTERN;

  public String toString() {
    throw new java.lang.Error();
  }

  @Nullable
  private String methodAndClassNamePatternGroupOrDefault(
      int group, @Nullable String defaultString) {
    Matcher matcher = METHOD_AND_CLASS_NAME_PATTERN.matcher(toString());
    return matcher.matches() ? matcher.group(group) : defaultString;
  }
}
