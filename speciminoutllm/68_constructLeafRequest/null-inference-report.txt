

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.runners.Suite.Suite(Class<?> klass, List<Runner> runners)` — parameter `klass` | `@Nullable` | `MaxCore` explicitly constructs a `Suite` with `(Class<?>) null`, so this parameter must be allowed to be null. |
| `org.junit.runners.ParentRunner.ParentRunner(Class<?> testClass)` — parameter `testClass` | `@Nullable` | `Suite` forwards its possibly-null `klass` to `ParentRunner`, and `ParentRunner` must therefore also accept a null test class. |

## B) Cause of the warning

The warning is caused by the expression `(Class<?>) null` on line 23 of `MaxCore.java`, which is passed as the first argument to the `Suite` constructor. Because `Suite` has no nullness annotations, NullAway treats its `klass` parameter as `@NonNull` by default, so passing an explicit `null` is flagged as unsafe. Marking `Suite`’s `klass` parameter as `@Nullable` tells NullAway that this constructor may legally receive null, and marking `ParentRunner`’s `testClass` parameter as `@Nullable` keeps the forwarded value consistent with its real nullability.
