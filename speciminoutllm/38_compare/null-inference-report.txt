

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `MaxHistory.getTestDuration(Description)` return type | `@Nonnull` | The comparator dereferences `getTestDuration(o1)` without a null check, so the result must be contracted as non-null for this call to be null-safe. |

No other parameters, return types, or fields are annotated because they are not required to resolve this warning.

## B) Cause of the warning

The warning points to:

```java
return result != 0 ? result : getTestDuration(o1).compareTo(getTestDuration(o2));
```

Here, NullAway sees that `getTestDuration(o1)` returns a `@Nullable Long`, but the code immediately dereferences that value by calling `.compareTo(...)`. That is unsafe because the returned `Long` could be null. Changing the return type of `getTestDuration` to `@Nonnull` tells NullAway that the method is guaranteed to return a non-null `Long`, so the dereference is safe.
