

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `Description` constructor parameter `Class<?> testClass` | `@Nullable` | `createTestDescription` intentionally passes `null` because a test-method description may not have an enclosing test class. |

## B) Cause of the warning

The warning points to the `null` literal passed as the first argument to `new Description(...)`. That argument corresponds to the constructor parameter `Class<?> testClass`, which is unannotated and therefore treated as `@Nonnull` by NullAway. The literal `null` is inherently `@Nullable`, so passing it to an unannotated parameter is reported as unsafe. Annotating `testClass` as `@Nullable` tells NullAway that null is a valid value for this constructor parameter.
