

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `TestCase.fName` | `@Nullable` (unchanged) | The field is explicitly initialized to `null` by the default constructor and is returned by `getName()`, so it may be null. |
| `TestCase.assertNotNull(String, Object)` parameter `object` | `@Nullable` | This parameter is the value being asserted by `assertNotNull`, so it must legally accept a possibly-null object such as `fName`. |
| Other parameters/return types involved in this call | unannotated, i.e. NonNull by default | No evidence shows they can be null, and they are not the cause of this warning. |

## B) Cause of the warning

The warning is triggered at `TestCase.runTest()` line 14 by the call:

```java
assertNotNull("TestCase.fName cannot be null", fName);
```

`fName` is annotated `@Nullable`, and the evidence shows it can really be null. However, the second parameter of the resolved `TestCase.assertNotNull(String, Object)` method is unannotated, so NullAway treats it as `@NonNull`. Passing a `@Nullable` value into that `@NonNull` parameter causes the warning.

Annotating the `object` parameter of `TestCase.assertNotNull` as `@Nullable` fixes the warning because it correctly expresses that `assertNotNull` accepts the possibly-null object it is checking.

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Modifier;
import javax.annotation.Nullable;

@SuppressWarnings("deprecation")
public abstract class TestCase extends Assert implements Test {

  @Nullable private String fName;

  protected void runTest() throws Throwable {
    assertNotNull("TestCase.fName cannot be null", fName);
    Method runMethod = null;
    try {
      runMethod = getClass().getMethod(fName, (Class[]) null);
    } catch (NoSuchMethodException e) {
      fail("Method \"" + fName + "\" not found");
    }
    if (!Modifier.isPublic(runMethod.getModifiers())) {
      fail("Method \"" + fName + "\" should be public");
    }
    try {
      runMethod.invoke(this);
    } catch (InvocationTargetException e) {
      e.fillInStackTrace();
      throw e.getTargetException();
    } catch (IllegalAccessException e) {
      e.fillInStackTrace();
      throw e;
    }
  }

  public static void fail(String message) {
    throw new java.lang.Error();
  }

  public static void assertNotNull(String message, @Nullable Object object) {
    throw new java.lang.Error();
  }
}
