

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert.assertArrayEquals(@Nullable String message, ...)` | `@Nullable` | The JUnit `message` argument is optional and the existing reproduction already treats it as nullable. |
| `org.junit.internal.ComparisonCriteria.arrayEquals(String message, Object expecteds, Object actuals)` parameter `message` | `@Nullable` | This is the callee that receives the optional JUnit failure message, so it must be allowed to accept `null`. |

No other annotations are needed to fix this specific warning.

## B) Cause of the warning

The warning is triggered on the call to `arrayEquals(message, expecteds, actuals)` in `Assert.assertArrayEquals`. The local parameter `message` is annotated `@Nullable`, but the called method `ComparisonCriteria.arrayEquals(...)` has an unannotated `String message` parameter. Since unannotated reference types are treated as non-null by NullAway, passing a `@Nullable` expression into that `@NonNull` parameter is reported as unsafe. Annotating `ComparisonCriteria.arrayEquals`’s `message` parameter as `@Nullable` tells NullAway that the callee accepts `null`, which resolves the warning.
