

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `JUnit4ClassRunner.testAborted(RunNotifier, Description, Throwable)` third parameter `e` | `javax.annotation.Nullable` | This parameter is called with `e.getCause()`, which is `@Nullable` according to `Throwable`/JDK stubs, so the receiving parameter must be allowed to accept a null value. |
| Other parameters/returns/fields in the reduced slice | no annotation change | They are not involved in this specific NullAway warning and should remain non-null by default. |

## B) Cause of the warning

The warning is on the call:

```java
testAborted(notifier, description, e.getCause());
```

`e.getCause()` comes from `Throwable.getCause()`, which NullAway treats as `@Nullable` because a `Throwable` may have no cause. However, the called method `testAborted` declares its third parameter as `@Nonnull Throwable e`, so NullAway reports that a potentially null value is being passed where a non-null value is required. Changing that parameter to `@Nullable Throwable e` makes the method contract accept the possibly-null cause and resolves the warning without changing program logic.
