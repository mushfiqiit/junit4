

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `ParentRunner.createTestClass(Class<?>)` parameter `testClass` | `@Nullable` | It is already intentionally nullable and simply forwards the value to `TestClass`. |
| `TestClass.<init>(Class<?>)` parameter `clazz` | `@Nullable` | The original constructor explicitly checks `clazz != null` before dereferencing, indicating that `null` is an acceptable argument. |

## B) Cause of the warning

The warning is reported on line 13 of `ParentRunner.java`, at the call `new TestClass(testClass)`. The variable `testClass` is declared `@Nullable`, but the `TestClass` constructor parameter `clazz` is unannotated, so NullAway treats it as `@NonNull`. Therefore NullAway flags passing a possibly-null argument to a non-null parameter. Marking the `TestClass` constructor parameter as `@Nullable` makes the call valid and matches the original null-checking behavior.
