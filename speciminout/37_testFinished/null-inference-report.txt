| `Long` value type argument in `starts` | `@Nonnull` | The stored values are boxed non-null `System.nanoTime()` timings and are retrieved only after a corresponding `testStarted`, so the unboxed `Long` is guaranteed non-null. |

B) Cause of the warning

The warning is on `long start = starts.get(description);`. NullAway treats the value obtained from `starts.get(...)` as a `@Nullable Long`, and assigning that value to a primitive `long` requires unboxing. If the `Long` were `null`, unboxing would throw a `NullPointerException`. Annotating the map as a non-null map containing non-null `Long` values tells NullAway that the unboxed expression is non-null, resolving this specific warning.
