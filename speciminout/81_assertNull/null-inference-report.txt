

### A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| `org.junit.Assert.failNotNull(String message, Object actual)` parameter `message` | `@Nullable` | The original `failNotNull` body explicitly handles a null `message` with `if (message != null)`, and JUnit assertion messages are optional. |

### B) Cause of the warning

The warning is on the call `failNotNull(message, object)` inside `assertNull`. `assertNull` declares its `message` parameter as `@Nullable`, but `failNotNull` declares its `message` parameter without a nullability annotation, so NullAway treats it as `@NonNull`. Passing the `@Nullable` `message` argument to that `@NonNull` parameter is unsafe under NullAway’s contract. Annotating `failNotNull`’s `message` parameter as `@Nullable` matches its actual usage and resolves the warning.

// === org/junit/Assert.java ===
package org.junit;

import javax.annotation.Nullable;

public class Assert {

  public static void assertNull(@Nullable String message, Object object) {
    if (object == null) {
      return;
    }
    failNotNull(message, object);
  }

  private static void failNotNull(@Nullable String message, Object actual) {
    throw new java.lang.Error();
  }
}
