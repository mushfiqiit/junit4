

## A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---:|---|
| Local variable `runMethod` in `junit.framework.TestCase.runTest()` | `@Nonnull` | The only path that can leave `runMethod` uninitialized/null ends in `fail`, which is intended to terminate execution, so at the dereference `runMethod` is treated as non-null. |

No parameter, return type, or field annotations need to be changed to fix this specific warning.

## B) Cause of the warning

NullAway sees `Method runMethod = null;` and therefore initially considers `runMethod` nullable. It does not know that `fail(...)` always throws and therefore cannot conclude that control flow cannot reach the `if` statement with `runMethod` still null. As a result, the receiver `runMethod` in `runMethod.getModifiers()` is considered `@Nullable`, causing the dereference warning.

Annotating the local variable as `@Nonnull` records the intended invariant that, by the time the method reaches the dereference, `runMethod` is non-null. This makes NullAway treat the dereferenced expression as non-null and resolves the reported warning. Any warning about the explicit `null` initializer is a separate warning and is not the one being fixed here.

package junit.framework;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Modifier;
import javax.annotation.Nonnull;
import javax.annotation.Nullable;

@SuppressWarnings("deprecation")
public abstract class TestCase extends Assert implements Test {

  @Nullable private String fName;

  protected void runTest() throws Throwable {
    assertNotNull("TestCase.fName cannot be null", fName);
    @Nonnull Method runMethod = null;
    try {
      runMethod = getClass().getMethod(fName, (Class[]) null);
    } catch (NoSuchMethodException e) {
      fail("Method \"" + fName + "\" not found");
    }
    if (!Modifier.isPublic(runMethod.getModifiers())) {
      fail("Method \"" + fName + "\" should be public");
    }
    try {
      runMethod.invoke(this);
    } catch (InvocationTargetException e) {
      e.fillInStackTrace();
      throw e.getTargetException();
    } catch (IllegalAccessException e) {
      e.fillInStackTrace();
      throw e;
    }
  }

  public static void fail(String message) {
    throw new java.lang.Error();
  }

  public static void assertNotNull(String message, Object object) {
    throw new java.lang.Error();
  }
}
