

A) Annotation decisions

|---|---:|---|
| `Assert.assertArrayEquals` parameter `String message` | `@Nullable` | This is the public JUnit-style optional failure message, and the warning is caused by passing this nullable value to an unannotated internal method. |
| `Assert.internalArrayEquals` parameter `String message` | `@Nullable` | The internal method is invoked directly with the public method's `@Nullable message`, so its `message` parameter must also be marked nullable. |

B) Cause of the warning

The warning occurs at the call `internalArrayEquals(message, expecteds, actuals)` inside `assertArrayEquals`. The `message` parameter of `assertArrayEquals` is annotated `@Nullable`, but the `message` parameter of `internalArrayEquals` is unannotated, which NullAway treats as `@NonNull` by default. Therefore, NullAway reports that a nullable value is being passed where a non-null value is required. Marking `internalArrayEquals`'s `message` parameter as `@Nullable` makes the call safe and matches the intended nullability of the optional JUnit message.
