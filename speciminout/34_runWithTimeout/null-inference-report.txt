| location | inferred annotation | one-sentence reason |
|---|---:|---|
| Return type of the anonymous `Callable<Object>` method `call()` in `MethodRoadie.runWithTimeout` | `@Nullable` | The method explicitly returns `null`, and the returned value is not dereferenced by the surrounding code, so it is legitimately nullable. |

B) Cause of the warning

The warning is caused by the anonymous `Callable<Object>` implementation:

```java
public Object call() throws Exception {
  runTestMethod();
  return null;
}
```

NullAway treats the unannotated return type `Object` as `@NonNull` by default. The statement `return null;` therefore returns a `@Nullable` expression from a method whose return type is considered non-null. Annotating the return type as `@Nullable` tells NullAway that this method may return null, which resolves the warning.
