## B) Cause of the warning

The warning is on line 15 in `readResolve()`:

```java
return new Result(serializedForm);
```

Here, `serializedForm` is a field annotated `@Nullable`, while the constructor parameter `SerializedForm serializedForm` is unannotated and therefore `@NonNull` by default under NullAway. NullAway therefore reports that a `@Nullable` value is being passed where a `@NonNull` value is required. Marking the `serializedForm` field `@Nonnull` tells NullAway that the value passed from `readResolve()` to the constructor is non-null, so the call satisfies the constructor’s nullability requirement.
