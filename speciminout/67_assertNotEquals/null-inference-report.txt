

A) Annotation decisions

| location | inferred annotation | one-sentence reason |
|---|---|---|
| `org.junit.Assert.failEquals` parameter `String message` | `@Nullable` | The original `failEquals` body explicitly checks `message != null`, and it is called from public `assertNotEquals` methods whose `message` parameter can be null. |

B) Cause of the warning

The warning occurs at the call `failEquals(message, Double.valueOf(actual))` inside `assertNotEquals`. The local parameter `message` in `assertNotEquals` is annotated `@Nullable`, but the reduced declaration of `failEquals` declares its first parameter as unannotated `String message`, which NullAway treats as `@NonNull`. Therefore, NullAway reports that a nullable value is being passed to a non-null parameter. Annotating the `message` parameter of `failEquals` as `@Nullable` correctly expresses that it may receive a null message and resolves the warning.
